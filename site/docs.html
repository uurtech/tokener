Deploy in 5 minutes

On a fresh Linux server with a DNS record pointing at it (ports 80 and 443 open):

curl -fsSL https://raw.githubusercontent.com/uurtech/tokener/master/deploy/install.sh \
  | sudo bash -s -- claude-gw.example.com

The script installs Docker if needed, writes /opt/tokener/.env with a random ADMIN_TOKEN and KEY_POOL_SECRET, starts tokener behind Caddy with automatic HTTPS, and prints the admin link. Use :80 instead of a domain for a plain-HTTP trial. Update with cd /opt/tokener && docker compose pull && docker compose up -d.

Just the container:

docker run -d -p 8080:8080 -v tokener:/app/data \
  -e ADMIN_TOKEN=change-me -e KEY_POOL_SECRET=change-me-too \
  -e STORE=sqlite -e SQLITE_PATH=/app/data/gateway.db ghcr.io/uurtech/tokener:latest

Optional extras in .env: ALERT_WEBHOOK_URL (Slack, Discord, Teams), and admin SSO with OIDC_ISSUER, OIDC_CLIENT_ID, OIDC_CLIENT_SECRET, OIDC_ALLOWED_DOMAINS (callback https://<gateway>/admin/sso/callback).

Quick start (local)

Nothing is deployed to AWS. You need Node 22.13+ and AWS credentials with access to the Anthropic models on Bedrock.

git clone https://github.com/uurtech/tokener.git && cd tokener/gateway
npm ci && npm run build
cp .env.example .env   # AWS_BEARER_TOKEN_BEDROCK (or IAM keys), AWS_REGION, ADMIN_TOKEN
npm run local

The output prints a one-click login link to the admin console. If ADMIN_TOKEN is empty, a random one is generated and printed. Or run it with Docker:

cd gateway && ADMIN_TOKEN=secret AWS_PROFILE=myprofile docker compose up --build

Developer setup

Create a developer in the console. Each developer adds this block to ~/.claude/settings.json:

{
  "env": {
    "ANTHROPIC_BASE_URL": "https://claude-gw.archeon.dev",
    "ANTHROPIC_AUTH_TOKEN": "cgw_...",
    "CLAUDE_CODE_GATEWAY_HINT_HEADERS": "1",
    "CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS": "1",
    "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY": "1",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "claude-haiku-4-5"
  }
}

CLAUDE_CODE_GATEWAY_HINT_HEADERS matters most: without it, every request counts as the main conversation and routing has nothing to work with.

Key pool: several keys, one endpoint

Open Keys in the console and add Anthropic API keys (sk-ant-…) and/or Bedrock API keys. Each key is tested with a free count_tokens call and then joins the rotation. Developers change nothing.

  • Per session (default): each Claude Code session sticks to one key, so the prompt cache stays warm, and new sessions are spread evenly.
  • Failover: on 429, 529, 5xx, 401/403 or "credit balance too low", the same request is retried on the next key. Request errors are never retried.
  • Proactive: an Anthropic key under 5% of any rate-limit bucket is parked until its reset time.
  • Fallback: when every key is out, the gateway's own AWS credentials can serve as a last resort. Without fallback, Claude Code gets a 429 with an honest retry-after.

Limits apply per Anthropic organization and per AWS account and region, so add keys from separate orgs or accounts to raise the total. Keys can also be shipped read-only from config:

KEY_POOL_SECRET=change-me   # encrypts stored keys (defaults to ADMIN_TOKEN)
PROVIDER_KEYS_JSON='[{"label":"org-a","kind":"anthropic","key":"sk-ant-..."},
                     {"label":"acct-2","kind":"bedrock","key":"ABSK...","region":"us-west-2"}]'

Reserve keys for a team with the key's Teams field, and give Bedrock keys their tokens and requests per minute so the gateway can switch before throttling. Each developer can follow their own usage at https://<gateway>/me, or with curl -H "Authorization: Bearer cgw_..." $GATEWAY/v1/me.

Deploy to AWS

Requires AWS CLI v2, Node.js 22+, Docker and AWS CDK v2. A domain and ACM certificate are optional; without them the ALB serves HTTP, which is fine for a POC only.

cd gateway && npm ci && npm test
cd ../infra && npm ci
npx cdk bootstrap   # first time per account/region
npx cdk deploy      # ~8 min
./scripts/create-dev-key.sh <KeysTableName> alice 25 backend 5000000
#                          name  USD/day team tokens/day

Configuration

The env block in infra/gateway.config.json sets the initial behavior. Policy saved from the console overrides it.

VariableDefaultDescription
BRIDGE_BEDROCKtrueStrips fields Bedrock rejects. Keep it on.
ROUTE_SUBAGENT_MODELemptyModel for subagent requests.
ROUTE_AUXILIARY_MODELemptyModel for titles and summaries.
EFFORT_MODEofffill or override.
TOOL_RESULT_MAX_CHARS020000 is recommended.
BUDGET_ACTIONwarnwarn, downgrade or block.
UPSTREAM_MODEmantlemantle or runtime. Switchable live.
KEY_POOL_SECRETADMIN_TOKENEncrypts upstream keys stored by the console.
PROVIDER_KEYS_JSONemptyRead-only pool keys from config.

The full list is in the README.

Testing

cd gateway
npm test         # unit tests (vitest)
npm run smoke    # end-to-end against fake Bedrock + Anthropic upstreams, incl. key-pool failover

Limitations

Bridging needs ongoing maintenance as Claude Code adds beta fields. Prices are estimates; Cost Explorer is the source of truth. Budgets reset daily at UTC midnight. Structured outputs and server-side tools are not available on Bedrock.
